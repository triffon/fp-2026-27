### Задача 1
Дефинирайте функции, които връщат:
 - по-малкото от две цели числа
    - добавете тест с отрицателни числа
    - използвайки `if-else` (`minIf`)
    - използвайки guards (`minGuard`)
    - използвайки вградена функция (`minBuiltIn`)
 - последната цифра на цяло число (`lastDigit`)
 - частното при целочисленото деление на две цели числа (`quotientWhole`) и резултата от „истинското“ им деление като реално число (`divWhole`)
 - цяло число без последната му цифра (`removeLastDigit`)
 - частното при делението на две реални числа (`divReal`) и цялата част на това частно (`quotientReal`)
 - средното аритметично на две цели числа (`avgWhole`)
 - числото, закръглено до два знака след десетичната запетая (`roundTwoDig`), и същото, но „с магия“ – чрез композиция на функции (`roundTwoDigButWithMagic`)

```haskell
print $ minIf 15 60 == 15
print $ minIf 60 15 == 15
print $ minIf (-15) (-60) == -60
print $ minGuard 15 60 == 15
print $ minGuard 60 15 == 15
print $ minBuiltIn 60 15 == 15

print $ lastDigit 154 == 4

print $ quotientWhole 64 2 == 32
print $ divWhole 154 17 == 9.058823529411764

print $ removeLastDigit 154 == 15

print $ divReal 154.451 10.01 == 15.42967032967033
print $ quotientReal 154.21 17.17 == 8

print $ avgWhole 5 1542 == 773.5

print $ roundTwoDig 3.1413465345321 == 3.14
print $ roundTwoDigButWithMagic 3.1413465345321 == 3.14
```

### Задача 4

### Задача 11
Дефинирайте функция `pythagoreanTriples :: Int -> [(Int, Int, Int)]`, която връща всички питагорови тройки `(a, b, c)` с `a < b < c <= n`, т.е. **a<sup>2</sup> + b<sup>2</sup> = c<sup>2</sup>**, в лексикографски ред.

Дефинирайте функция `goldbach :: Int -> (Int, Int)`, която за четно число `n > 2` връща първата двойка прости числа `(p, q)` с `p <= q` и `p + q = n` (хипотезата на Голдбах твърди, че такава двойка винаги съществува). Използвайте `isPrime` от Задача 8.

> Забележка: Използвайте **list comprehension**

```haskell
print $ pythagoreanTriples 20 == [(3,4,5),(5,12,13),(6,8,10),(8,15,17),(9,12,15),(12,16,20)]
print $ pythagoreanTriples 5 == [(3,4,5)]

print $ goldbach 4 == (2,2)
print $ goldbach 28 == (5,23)
print $ goldbach 100 == (3,97)
```

<details>
<summary><b>💡 Покажи подсказка</b></summary>

<br>

В list comprehension може да има повече от един генератор - `[(a, b) | a <- [1 .. n], b <- [a + 1 .. n]]` обхожда всички двойки с `a < b`, като всеки следващ генератор може да използва променливите от предишните. Добавете трети генератор за `c` и условие за питагоровото равенство. За `goldbach` е достатъчно `p` да обхожда простите числа до `n / 2` (тогава `q = n - p >= p`), а първият елемент на получения списък се взима с `head` - заради мързеливото оценяване останалите двойки изобщо няма да бъдат пресметнати.

</details>

Номерът е, че в Haskell `String` е просто `[Char]` - списък от символи, - така че върху „показаното“ число работят всички функции за списъци, които вече познавате: `reverse`, `length`, `map`, `sum`, ...

> Забележка: `read` може да произведе стойност от всякакъв тип (число, списък, ...), затова трябва да знае какво се очаква - в случая това се разбира от сигнатурата на функцията. Опитайте какво става, ако я махнете. Следващата седмица ще се занимаваме много по-подробно с низове.

### Задача 13 :elevator:
Асансьорът в блок 55 на Студентски град е обладан от духа на стар преподавател по Дискретни структури и отказва да се подчинява на бутоните. Ако Гошо влезе в него на четен етаж `n`, асансьорът го откарва на етаж `n / 2`, а ако влезе на нечетен етаж - на етаж `3n + 1`. Спира да се движи само когато стигне до етаж 1, откъдето Гошо най-после може да избяга пеша. Блокът е безкрайно висок (проклятието и на Столична община), така че етажи не свършват.

Дефинирайте функция `elevatorStops :: Int -> Int`, която връща броя на пътуванията с асансьора от даден етаж до етаж 1 (от етаж 1 Гошо изобщо не се качва). После дефинирайте `longestElevatorRide :: Int -> (Int, Int)`, която за етажите от 1 до `n` намира този, от който пътуването до етаж 1 е най-дълго, и връща наредената двойка `(етаж, брой пътувания)`.

> Забележка: Това е известната хипотеза на Колац - никой не е доказал, че асансьорът винаги стига до етаж 1, но за всички етажи, които някой някога е пробвал, стига.

```haskell
print $ elevatorStops 1 == 0
print $ elevatorStops 6 == 8
print $ elevatorStops 27 == 111

print $ longestElevatorRide 10 == (9, 19)
print $ longestElevatorRide 100 == (97, 118)
print $ longestElevatorRide 1000 == (871, 178)
```

<details>
<summary><b>💡 Покажи подсказка</b></summary>

<br>

Постройте с list comprehension списъка `[(elevatorStops k, k) | k <- [1 .. n]]` и вземете `maximum`-а му. Кортежите се сравняват лексикографски - първо по първата компонента и само при равенство по втората, - затова е важно броят пътувания да е **първата** компонента, за да сравнява `maximum` именно по него. Накрая разменете компонентите на резултата, за да получите `(етаж, пътувания)` - това става удобно с pattern matching в `where`.

</details>
