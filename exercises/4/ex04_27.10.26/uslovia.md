## Атоми
Числа, низове, символи, булеви стойности.

```scheme
(define atom?
  (lambda (x)
    (and (not (pair? x)) (not (null? x)))))
```

## Предикатите `eq?`, `eqv?`, `equal?`
Имаме следното включване:  **`eq?` ⊂ `eqv?` ⊂ `equal?`** 

  - `eq?` =  еднакви обекти в паметта + **в зависимост от имплементацията и за атоми**

```scheme
(eq? "a" "a") ; #t
(eq? 2.5 2.5) ; #t
(eq? (/ 5 2) (/ 5 2)) ; #f
(eq? '() '()) ; #t
(eq? (list 1 2) (list 1 2)) ; #f 
(eq? 1 1.0) ; #f
(eq? 0.5 (/ 1 2)) ; #f
(eq? (inexact->exact 0.5) (/ 1 2)) ; #f
```
 - `eqv?` =  `eq?` + атоми

```scheme
(eqv? "a" "a") ; #t
(eqv? 2.5 2.5) ; #t
(eqv? (/ 5 2) (/ 5 2)) ; #t
(eqv? '() '()) ; #t
(eqv? (list 1 2) (list 1 2)) ; #f 
(eqv? 1 1.0) ; #f
(eqv? 0.5 (/ 1 2)) ; #f
(eqv? (inexact->exact 0.5) (/ 1 2)) ; #t
```
 - `equal?` =  `eqv?` + списъци
```scheme
(equal? "a" "a") ; #t
(equal? 2.5 2.5) ; #t
(equal? (/ 5 2) (/ 5 2)) ; #t
(equal? '() '()) ; #t
(equal? (list 1 2) (list 1 2)) ; #f 
(equal? 1 1.0) ; #f
(equal? 0.5 (/ 1 2)) ; #f
(equal? (inexact->exact 0.5) (/ 1 2)) ; #t
```
- `=` сравнение на числа , т.е. сравнява ги независимо от типа
```scheme
(= 1 1.0) ; #t
(= 0.5 (/ 1 2)) ; #t
(= "a" "a") ; грешка -> очаква число
```

Ако ще сравнявате числа използвайте `=`, защото работи за всички видове.
Ако ще сравнявате списъци използвайте `equal?`.

## Списъци
Достъпване на списъка:
```scheme
(car '(1 2 3 4)) ; -> 1
(cdr '(1 2 3 4)) ; -> '(2 3 4 5)
```
Можем да образуваме списъци чрез `'( ...)` и `(list ...)`. 
  -  `'( ...)`  образува структура без да оценява елементите
  -  `(list ...)` използва процедурата `list`, за да образува списък и съответно оценява елементите
```scheme
'(1 2 (+ 2 3)) ; -> '(1 2 (+ 2 3))
(list 1 2 (+ 2 3)) ; -> '(1 2 5)
(caddr '(1 2 (+ 2 3))) ; -> '(+ 2 3) - третира третия елемент като списък с три елемента
(caddr (list 1 2 (+ 2 3))) ; -> 5 - първо е оценило елемента и съответно третият елемент е число
(caaddr '(1 2 (+ 2 3))) ; -> '+
(caaddr (list 1 2 (+ 2 3))) ; -> caaddr: contract violation
                            ;      expected: (cons/c any/c (cons/c any/c (cons/c pair? any/c)))
                            ;      given: '(1 2 5)
```

Припомнете си `length`, `reverse`, `map`, `filter`. Напишете свои версии на тези функции.

## `foldr` и `foldl` -  като `accumulate`, но за списъци

```scheme
(define (foldr operation null_value lst)
  (if (null? lst) null_value
      (operation (car lst)
          (foldr operation null_value (cdr lst)))))

(define (foldl operation null_value lst)
  (if (null? lst) null_value
      (foldl operation (operation null_value (car lst)) (cdr lst))))
```
